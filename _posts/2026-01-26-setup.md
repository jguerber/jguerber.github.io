This website is generated using the [al-folio](https://github.com/alshedivat/al-folio) template for [Jekyll](https://jekyllrb.com/), a static web page builder. Here's what I did to get it working.

## Setting up a webpage repository

I forked the template repository and used my fork as a template for the [jguerber.github.io](https://www.github.com/jguerber/jguerber.github.io) repository. This allows GitHub Actions and GitHub Pages to take care of the webpage deployment.

## Local development

To render the website on my personal laptop to get it working and up-to-date before publishing to GitHub, i use the Docker tutorial on the [installation tutorial](https://github.com/alshedivat/al-folio/blob/main/INSTALL.md). Run `docker compose build`, then `docker compose up` and I could access the development version of the website at `localhost:8080` on my browser.

## Template customization

See [al-folio tutorial](https://github.com/alshedivat/al-folio/blob/main/CUSTOMIZE.md) for details. The template comes with a lot of pre-written sample pages, which can be deleted, moved or disabled. Pages accessible from the navigation bar are defined in the `/_pages` directory, where the yaml headers have nice options. For example, to hide a section from the navigation bar, set `nav: true` to `nav: false`. The home page content can be edited in the `_config.yml` file.
